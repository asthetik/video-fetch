# MiSans 字体来源与使用说明

- 来源：小米官方字体页面 https://hyperos.mi.com/font/（下载包 MiSans.zip，v1.1，2025-01 构建）
- 授权：小米官方声明 MiSans 可全球免费商用，允许嵌入软件分发；嵌入使用时需在软件中注明使用了 MiSans 字体（本项目在「关于」页第三方组件区块与 THIRD_PARTY.md 中注明）。
- 本目录中的 `MiSans-400/600/700/800.woff2` 为子集化产物：以 fontTools pyftsubset 按「GB2312 全集 + 应用界面字符」子集，仅包含所需字重与字形，用于控制安装包体积。完整字体请从官方页面获取。
