# Sidecar version pins — single source of truth for release packaging.
#
# Any version bump here also needs new SHA-256 digests in
# sidecar_pins.json. Run `python scripts/fetch_sidecars.py --update-pins`
# right after a bump (digests are cross-checked against upstream's own
# checksum files). The new version is a new pin key — `yt-dlp_linux`
# becomes `yt-dlp_linux@<tag>` — so it is recorded without --force, which
# stays reserved for a digest that changed under an unchanged key.
#
# yt-dlp: auto-upgraded by Dependabot (pip ecosystem, see
# .github/dependabot.yml). PyPI normalizes the version string
# (GitHub tag 2026.08.19 -> PyPI 2026.8.19); fetch_sidecars.py
# zero-pads it back to the GitHub release tag.
#
# ffmpeg: BtbN (Linux/Windows) and martin-riedl (macOS arm64) ship raw
# binaries with no package-registry ecosystem for Dependabot to track —
# pinned as FFMPEG_VERSION, FFMPEG_BTBN_TAG and FFMPEG_MACOS_BUILD in
# scripts/fetch_sidecars.py and bumped manually.
yt-dlp==2026.8.19
